# pos-system

Punto de venta responsive con escaneo QR/barras por cámara | React + Node.js + SQLite

## Integrantes

- Claudio Patricio Rojas Rodríguez
- Andrea Jackeline Ávila Martínez

## Tecnologías

- Frontend: React + Vite
- Backend: Node.js + Express
- Base de datos: SQLite
- Escaneo: html5-qrcode

## Instalación

```bash
# Backend
cd backend
npm install
npm run dev

# Frontend
cd frontend
npm install
npm run dev
```
